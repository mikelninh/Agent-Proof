One fair comparison.

Single agent versus coordinator + builder + independent verification/review. The baseline gets the same tools and source material. Count the coordinator's costs too.

Then compare the same team with and without Buzz to isolate whether the shared workspace itself helps.

Earn the next stage.

First: verified artifact. Then: paired productivity evidence. Next: accepted real work and a seven-day defect check. Business proof is a customer payment and repeat use—not an estimated revenue chart.

Twenty task pairs give an exploratory signal, not general proof. Repeat on unseen tasks. Do not change thresholds or expose held-out answers to make a version pass.

No theatre in the telemetry.

The interface distinguishes evidence from ambition.

Built in this pilot

Role-token checks, durable SQLite mission state, independent proof/review stages, artifact-bound human approval, bounded revisions and budget units, cancellation, and a hash-chained audit log.

The paired scorecard rejects mismatches and duplicates, excludes fixtures, includes failed work in unit costs, and treats missing measurements as unknown.

Not established

Live LLM workers, end-to-end Buzz delivery/readback, isolated agent machines, production deployment, savings, revenue, or sustained customer outcomes.

Hash chaining is not identity signing or tamper-proof storage. Anchor the log head externally. The budget units are not a provider-enforced spending cap.

Evidence manifest
Source replay is included in the export. Local timestamps are replay execution times. The scorecard consumes operator-supplied measurements; it does not authenticate provider invoices.
