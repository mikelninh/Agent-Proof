# RETROSPECTIVE

v0.3 closes an important product gap: Agent Proof no longer only says whether one agent is good enough. It can now answer the operational release question, **“is this candidate safer/better than what we had before?”**

The bundled 87% → 97% offline demo makes the release-decision workflow immediately visible. The next commercial proof point is still external: one real team should bring anonymised historical cases and ask Agent Proof to adjudicate an actual model/prompt/agent change.
